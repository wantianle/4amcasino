# 牌桌重构 & 新玩法 — 需求与设计定稿

来源：用户多轮试玩反馈 + 四轮问答确认。分两阶段：**P1 牌桌 UI 重构（前端）**、**P2 新玩法（前端+服务端）**。
总原则：全面向 ClubGG / GGPoker 对齐。

---

## P1 — 牌桌 UI 重构

### 目标布局（桌面）
单一「牌桌区」，把右侧栏与底栏全部收拢进牌桌区；不再有常驻右栏/底栏。

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：房间名/码 · [自动发牌·下一手休息·行动计时] · [出牌记录·账本] · 麦·聊·全屏·⋮ │
├──────────────────────────────────────────────────────────────┤
│                     ┌ 底池·文字胶囊 ┐                           │
│                     └ (公共牌正上方) ┘                         │
│        ┌──────────── 固定椭圆牌桌（等比缩放，不变形） ───────────┐   │
│        │   座位（深色圆角 pod：头像/名字/筹码；D 在 felt 上）   │   │
│        │              公共牌 / 底牌区（随桌缩放）               │   │
│        └──────────────────────────────────────────────────────┘   │
│  [下手牌离座]                                  [下注区/比例·右下角] │
│  [排名][聊天]（按钮→浮层）                                         │
└──────────────────────────────────────────────────────────────┘
```

### 逐项
| # | 项 | 定稿 |
|---|---|---|
| A1 | 响应式 | 布局最小 **1280×720**；低于则**先省文字只留图标** → 再不够**整块牌桌区等比缩小**（不换行、不溢出） |
| A2 | 底牌区 | 去掉固定尺寸，**随牌桌等比缩放** |
| A3 | 牌桌形状 | **锁定当前椭圆宽高比**，等比缩放，**绝不随窗口拉扁** |
| A4 | 人物框 | **去掉方块描边框，保留深色半透明圆角 pod 底**；保留**头像 / 名字 / 筹码数 / 状态**（D 独立摆在 felt 上；不使用 SB/BB 座位徽章） |
| A5 | 底池 | **底池使用公共牌上方的深色文字胶囊显示**；筹码堆只显示在下注玩家的 bet point，不在中央重复绘制 |
| A6 | 排名 / 聊天 | 从右栏收进牌桌区，均为**按钮 → 弹出浮层**；聊天浮层含输入框 + 快捷语 + 表情 |
| A7 | 底栏 | 底池/状态/余额/快捷键等**并入牌桌区**，不再有独立底栏 |
| A8 | 下注区 | 移到牌桌区**右下角**，仿 ClubGG（**待用户提供 ClubGG 截图后再做**） |
| A9 | 下手牌离座 | 移到牌桌区**左下角** |
| A10 | 下注比例 | 默认五档 `1/3、1/2、3/4、1、1.5`（可选全下及 1/4、2）；**设置页统一配置**（存账号，牌桌读取）；旧四槽或非法配置在读取/保存时一次性回退为五档默认值（`sanitizeBetRatios`，`apps/server/src/profile.ts`） |
| A11 | 总原则 | 对齐 ClubGG / GGPoker |
| — | 移动端 | **同步重构为同一套**（不是沿用旧 MobileTable 布局） |

## P2 — 新玩法（严格按用户截图规则；需改 server + DB）

| # | 玩法 | 定稿规则 |
|---|---|---|
| B1 | **鱿鱼游戏** | **仅手动**触发（房主开）。触发后：**未获胜者**向**其他所有参赛者平分**支付罚金，罚金 = `nBB × (参与人数 − 1)`，从桌面筹码扣。`n` **房主可设，默认 1×BB**。可设**最低玩家数**（不达标不触发）。 |
| B2 | **计时银行** | 开关。每人**初始 X 秒**时间银行；**每 N 手补 Y 秒**。默认 **X=30、N=30手、Y=30秒**，参数可调。 |
| B3 | **炸弹池** | 设置后按**手数或时长**激活（`schedule.mode: 'hands' \| 'duration'`）；触发**手动 + 定时都要**。激活手每人须付**炸弹池前注**（按大盲，**1×/2×/3× 可选，默认 1×**）方能参与；**跳过翻牌前下注**。**双牌面本期不做**。 |
| B4 | **全下多次发牌** | 全下且仍有未发牌时：**服务端按实时胜率判定优势方**；**劣势方选择发牌次数 1–3**；**优势方同意才发**；**拒绝 → 退为发 1 次**；**多人池只发 1 次**；**鱿鱼游戏**中允许多发，但**只有全赢才拿下鱿鱼**。 |
