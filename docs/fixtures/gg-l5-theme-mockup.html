felt 主色 / 径向中心 → 边缘#8c1828 → #5f0d19 → #28070f推断：根据桌面参照图内圈红色区域取视觉近似；不是像素采样。
rail 木质主色 / 高光 / 暗边 / 金线#8a4b22 / #d29a56 / #2a120d / #d6a832推断：参考桌面图的暖棕 rail、亮边和细金色内圈。
金色（文字/环/D/胶囊）#e7b83e；高光 #fff0a0推断：从桌面 pot、头像装饰环和 D 盘的共同色相归纳。
卡背主色 / 花纹#812532 / 45° repeating stripe + faint radial motif推断：参照图牌背为红褐色细纹，本稿用 CSS 花纹表达方向。
等级徽章底色#2466a0，白字、浅蓝描边推断：来自桌面参照中蓝色等级牌的视觉关系。
桌面 felt 外缘宽高比约 1.65:1量取/复核：桌面参照图 1176×888 内部可见桌体为横椭圆；精确外缘受头像与 rail 遮挡，故只记录约值。
手机 felt 外缘高宽比1.40:1（400×560 设计画布）量取：本项目已确定的手机设计画布 400×560；不是从 1242×2208 宣称量取。
头像直径 / 桌宽约 9%（桌面）；手机约 9%近似量取：桌面参照图可见头像圆与 felt 宽度的比例；受不同头像外环/裁切影响，供设计预算使用。
pot 胶囊字号/颜色/描边22px / #e7b83e / 1px #a72232（桌面）；手机 13px + chip stack推断：字号按 1176×888 设计稿的目标可读性确定；颜色取金字红底关系。
直接量取 vs 推断：参照图尺寸来自资源标称/文件尺寸；桌面 1.65:1 与头像约 9% 是对 gg-desktop-2026-pokerfuse-table.png 可见桌体/头像的近似量取。手机 1.40:1 是项目画布契约，不是参照图测量。颜色、字体、牌背花纹、具体间距和字号均是设计推断，不能当作产品现状或像素验收值。
