## 二、座位单元 —— 桌面与手机**同构**（核心）

一个座位 = **圆形头像** + **头像正下方的深色半透明圆角胶囊**：

- **头像**：直径约为桌宽的 **9%**（桌面端），挂在椭圆**外缘**；头像可带装饰环/头像框。
- **信息胶囊**（在头像正下方，压着桌沿略朝桌内）：
  - 第 1 行：**名字**（白色）
  - 第 2 行：**筹码**（金色）
- **蓝色六边形计时徽章**贴头像**左下角**。~~国旗贴头像右下角~~ —— **国旗不做**（用户 2026-10-06 裁决：国旗 UI 不用做，已有实现 `table-seat-flag` 应移除）。
- 手机端同样结构，只是整体更小更紧凑。

## 三、牌的呈现

- **弃牌态**：两张牌背**插在头像后方，与头像明显重叠**，牌背顶部高出头像。**这是正常设计，不是 bug。**
- **摊牌态**：牌浮在**头像上方**（不挡正脸）。
- **hero（自己）**：
  - 桌面端：手牌压在 **felt 内下缘**，位于头像/pod **上方**，与其它座位同构。
  - 手机端：hero 手牌**大幅放大**，占据牌桌底部中央（ClubGG 那张里 hero 牌大到占满底部）。

## 四、牌桌本体与公共区

- **桌形**：桌面端**横椭圆**（宽高比约 1.65:1）；手机端**竖椭圆/钟形**，向下延伸。
- **底池**：**中央上方**。
  - GG 桌面：**纯文字胶囊**「Total Pot : $1,850」（金色字），**无筹码堆图标**。
  - GG 手机：筹码堆图形 + 数字。
  - ClubGG 手机：**文字胶囊**「Total Pot / 57,000」。
- **公共牌**：**中央一排 5 张**，大号；手机端明显放大。
- **下注筹码**：摆在**下注者与中央之间**的 felt 上，**筹码堆图形 + 金额数字**（每个下注者一侧）。
- **庄家 D**：黄色圆盘，摆在 **felt 上**（不在座位旁）。**桌面端没有 SB/BB 字母徽章。**

## 五、明确禁止的验收判据（踩过的坑）

1. **不得**把「弃牌牌背 ∩ 头像 = 0px²」当作通过条件 —— GG 里牌背**本来就与头像重叠**。把重叠当 bug 修，会把设计做反。
2. **不得**用「矩形不重叠」这类通用直觉替代参照结论。涉及"参照某产品还原"的验收，必须把**参照结论本身**（谁盖谁、谁在桌内/桌外、相邻关系、目标比例）写进 gate 判据。
3. **不得**在"我们的座位根本没有头像"的结构上，去讨论"牌背该不该遮头像"。

## 六、我们当前的实际差距（2026-10-06 截图核对）

1. **座位上根本没有头像** —— 我们的座位只是一块「牌背 + 名字 + 筹码」，没有圆形头像，没有计时徽章/国旗。**这是最根本的差距。**
2. 牌背**浮在名字块上方**，而不是插在头像**后方**并与其重叠。
3. 公共牌区 fixture 曾在 preflop 显示公共牌（探针 bug）。
4. 桌面中央还残留发牌动画的牌堆起点（红色牌背）。
5. 底池已是文字胶囊 ✓，但下注筹码堆的呈现方式与 GG 不同。

## 七、改造方向

**第一步是把座位单元换成「头像 + 下方信息胶囊」这个骨架**；骨架对了，牌背与头像的遮挡关系、计时/国旗位置、hero 与其它座位的同构关系会自然成立。不要继续在旧骨架上挪魔法数字。
